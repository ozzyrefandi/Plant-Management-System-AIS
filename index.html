⚠️ Terbuka via file:// (Bukan Web Server)

Browser modern memblokir file JavaScript (ES Modules) jika file HTML dibuka langsung lewat klik ganda (protokol file:///) demi alasan keamanan (CORS).

Cara Mudah Membuka Offline:

  1. Klik dua kali file start-offline.bat (Windows) atau jalankan ./start-offline.sh (Mac/Linux) di folder aplikasi ini.
  2. Atau buka Terminal di folder ini dan jalankan:
    npm run preview atau npx serve dist
  3. Jika menggunakan VSCode, klik kanan index.html → Open with Live Server.
